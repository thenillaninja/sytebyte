SyteByte Help

User Guide

Build, customize, save, and publish a complete business website.

Getting Started Business Details Brand & Visuals Services Social Proof Pages & Sections Links Projects Publishing Workflow Troubleshooting
01

Getting Started

SyteByte turns structured business information into a polished, responsive website. Start with the business information, choose the visual style, configure content and pages, then generate the site.

Use Load Demo Business if you want to explore SyteByte with sample content before starting a real project.

02

Business Details

Enter the core information that identifies the business: business name, tagline, description, phone number, email, location, ZIP code, and service areas.

This information is reused throughout the generated website, including the hero, contact areas, calls to action, and footer.

03

Brand & Visuals

Choose the site template, hero layout, colors, textures, motion, and imagery. You can upload a business logo, hero image, and gallery images.

Templates provide a starting structure. They do not prevent you from changing, reordering, adding, or removing sections later.

04

Services & Availability

Add the services the business provides and its operating hours. Enter one service per line so SyteByte can turn them into individual service items in the generated site.

05

Social Proof & Content

Add optional testimonials, FAQs, gallery content, and other supporting information. These sections help make a generated site feel complete without requiring every field to be filled.

06

Pages & Sections

The Page Manager controls the pages in the website. Home is always the main index.html page. Additional pages can be created from starter templates such as About, Services, Gallery, Collection, Contact, or Blank.

Inside each page, sections can be enabled, disabled, reordered, renamed for navigation, and customized independently.

07

Linking Buttons & Content

Structured links allow buttons, products, collections, and promotional sections to link to another page, a section within the website, or an external URL.

Use Page or Section links whenever possible so SyteByte can automatically generate the correct destination in the published website.

08

Saving & Importing Projects

Save Project stores the editable SyteByte project as a .sytebyte.json file. This contains the project structure, pages, content, design choices, and supported uploaded imagery.

Use Import Project to reopen that file later and continue editing where you left off.

09

Publishing the Website

Use Publish Files when the site is ready. SyteByte creates a ZIP containing the generated website pages.

The Home page is exported as index.html. Additional pages are exported using their page slugs. The files can then be uploaded to a static web host or web server.

10

Recommended Workflow

  1. Enter Business Details.
  2. Choose a template and visual style.
  3. Add services, hours, and supporting content.
  4. Generate the site.
  5. Adjust pages and sections while watching the live preview.
  6. Configure buttons and links.
  7. Save the editable project.
  8. Publish the final website files.
11

Quick Troubleshooting

My changes are not showing.

Generate the site once to activate the live preview. Most text and settings will then update automatically as you edit.

I changed an uploaded image.

Image changes may require pressing Generate Site again before they appear.

I want to continue editing later.

Save the project before closing SyteByte, then import the resulting .sytebyte.json file next time.

I only want the finished website.

Use Publish Files. The published ZIP is separate from the editable SyteByte project file.
